# Staircase (Elephant Protocol)

> Staircase, Inc. operates the Elephant Protocol (elephant.xyz), a decentralized network that aggregates and verifies fragmented property and address records into trusted, agent-consumable data. It currently offers 500,000+ enriched property data points, an Enterprise API, a published Model Context Protocol (MCP) server, a CLI, and a library of Agent Skills for county-data ingestion. Backed by Bessemer Venture Partners.
